# YAM — Your Adventure Mobile

A MUSH/MUD client for Android, built for text-based worlds on the go.

YAM lets you connect to MUSHes, MUDs, and other MU* games from your phone —
full telnet support, ANSI color, per-world profiles, triggers, and slash
commands, all wrapped in a modern Android interface designed for actually
being usable on a small screen.

## About

YAM is a ground-up, mobile-native MUSH/MUD client — its code, architecture,
and design are wholly original. It does owe a nod of inspiration to *Potato*,
the long-running desktop MUSH client written by Mike Griffiths: studying how
Potato approached this problem helped shape what a good MU* client should
feel like. But a desktop client built for a mouse and a full keyboard is a
different animal from one built for a phone in your pocket, so YAM isn't a
port or a clone — it's its own take on the same idea, built for mobile from
the ground up.

*Thanks for the inspiration, Mike — and everyone still keeping these old
worlds alive.*

## Features

- Full telnet connection handling with reconnect support
- ANSI / truecolor rendering
- Per-world connection profiles
- Triggers and slash commands
- Session logging
- Built with a modern Android/Kotlin stack
